Introduction

Welcome to the Let's Do Diddly Puzzle Editor Manual. This document should help to explain how to use the Diddly Editors for creating Puzzles for Regular and Bonus round play. If you have questions, please contact Trilobyte Games.

Puzzle Editor Tutorial

To get you started on the right foot, you may find it helpful to go step by step through this tutorial.We recommend going through the Tutorial section first to familiarize yourself with the process and the control buttons. Pay attention to the Tips, as following them will help ensure that your Puzzles are acceptable.

If you haven't played the Let's Do Diddly demo by now, please do so. Otherwise, the purpose of creating puzzles using this editor will not be apparent.

General tips for Diddly puzzle creation

You can create as many of either type as you wish, however you should ideally try to create roughly two Regular Puzzles for every one Bonus Round Puzzle.

Creativity counts. This is a word play game, so put the most of clever wordplay into each and every Puzzle and Trivia Question. You may be direct and straightforward with clues within one particular Puzzle, in which case you would categorized it as a Puzzle of the "Easy" variety.

Tip: Make every attempt to check your spelling and your facts. Correct spelling is always important here and accurate facts are particularly important in the Trivia Questions.

Author Identification Dialogue Box

The first thing to appear is a dialogue box requesting your name and your contact information. The contact info can consist of email address or phone number, street address or all of these. After you've provided this information for the first time, if you intend to continue work on a previously saved file, you can choose to "Cancel" here. When you intend to start with a fresh Puzzle file, these boxes should be filled in once again.

Tip: By selecting the Author dialogue box during Puzzle editing, you can change your Author ID information.

New Regular Puzzle


Regular Puzzle

Select the New Regular button. This creates a brand new Puzzle within the current Puzzle file. Although the new Puzzle has no entries, let's save the file at this point anyway.

Save File

In the File Buttons palette, click the red Safety button. This activates the buttons in the palette. Select the Save button. In the dialogue box at the bottom of the new Save Puzzle window, type in a Puzzle file name and hit <Return> or click OK. The Puzzle File Label box shows the name of the work file. (Once editing changes have been made to the file, three asterisks will be displayed at the end of the filename.)

Tip: Note that as you work on the Puzzle file, you are working in an "editing space" and are not writing to the file saved on disc until you use the Save button.

Tip: Make good use of the Tool Tips by placing the cursor over the control buttons and dialog boxes.

Answer

Select the Answer dialogue box. It inverts color which indicates that it is active. Type in the Answer to the Puzzle. Of course, the Answer to the Puzzle is the one thing that the Puzzle Words have in common. The Answer can be two or more words or phrase, but should be limited to 26 characters including spaces. The shorter, the better, generally speaking.

Tip: Better to have the Answer be one word rather than two. If it is an uncommon name, for instance, like Albert Einstein, simply "Einstein" will do as the prefered answer.

Tip: Please use the singular over the plural whenever you can. The answer "Dog" is preferable to "Dogs", so remember to construct your puzzles, especially in terms of the Puzzle Clue, accordingly.

Puzzle Word List

Select a slot in the Puzzle Word List. Type in a Puzzle word.

Tip: Use <F1> to tab to the next field. (Sorry about not being able to use the Tab key here) Type in a few more words. After editing dialogue boxes, you may use <Return> or click outside the field box.

You'll notice that the new Puzzles start with ten spaces pre-set. This would be the minimum number of words required for a Puzzle. Use the Add button in the Word Buttons palette to make room for more Puzzle Words.

Check Marks

A check mark indicates that the word is an active word in the list. You may check and uncheck words to test out how they work together with the Test Puzzle feature.

Puzzle Words consisting of multiple word are allowed, although discouraged. Spaces are not used, therefore not allowed to be entered in the Puzzle Word fields.

Tip: Try typing in a Puzzle Word that is 10 characters or more. The field box turns Yellow as a warning only. This indicator is there simply because longer words may be harder to fit within or co-exist with other words in the matrix. The maximum word length allowable for Puzzle Words is 15 characters.

Notice: The Total Point Value and the total number of letters is shown at the bottom of the Puzzle Words List. Since letters in the Puzzle have point values, as in Scrabble, this value goes up as you enter more words, indicating the point "richness" of the Puzzle.

Puzzle Clue

Now click the Puzzle Clue dialogue box. Type in the Puzzle Clue. This is usually a phrase or a sentence. Notice that, as opposed to Answer and Puzzle Words fields, upper and lower case counts in this field.

Punctuation Rules for Puzzle Clues and Puzzle Word Clues

  • Use single quotation marks where you would normally use double quotation marks.
  • Use periods between sentences, but not at the end of a single sentence. This is the convention used in crossword puzzle clues.
  • For creating blank spaces for missing words, use the same number of underscores as there are in the missing word.
  • Although Puzzle Clues and Puzzle Word Clues are very similar to conventional crossword puzzle clues, please do not use abbreviations such as e.g., a.l., etc... Remember, these clues will be spoken by the gameshow host.

Test Clue


Test Clue

The Puzzle Clue can be more than one phrase or sentence, however length is an issue. Use the Test Clue feature to insure that it won't get clipped when displayed on screen.

Tip: Notice how buttons in the Word Buttons and Edit Buttons palettes change when dialogue or field boxes in the editing section are selected.

Test Puzzle


Test Puzzle

Select the Opt button. This optimize button reorders the words in a way designed to generate a puzzle very quickly. Next, select the Test Puzzle button. Use the Re-Test button a few times. The thing to watch for here is that the Puzzle will generate within a few seconds. The color indicator will turn yellow, then red if it takes too long. In that case, alter the Puzzle by checking or unchecking a word or two and then re-testing. Make sure you do not uncheck any key Puzzle Words, i.e., those required to point to the one correct answer.

Tip: The more densely packed with words the board is, the better. Add as many Puzzle Words as you can until they can't all fit on screen, and then experiment by checking and unchecking words until a puzzle can be generated in a short time. (Within the green or yellow parameters)

You may exit the Test Puzzle program by selecting the Cancel button. The Cancel button also interrupts the test especially in the event that it gets caught in an endless loop.

Category Selection

Single click the Category dialogue box. Load "Category Suggestions. CAT" from the file selection window. Use the plus and minus boxes to expand and collapse the category tree. Select an appropriate category for the current Puzzle from the list. If there is no suitable category, you can create one of your own later. For now, just choose one that comes closest. Highlight the choice and click the OK button.

Puzzle Difficulty

Choose the difficulty level for the current Puzzle. The default is "Norm".

Tip: Try to make roughly 50% of your Puzzles "Norm", 25% "Easy" and 25% "Hard".

New Bonus Puzzle


Bonus Puzzle

Select the New Bonus button. This creates a new Bonus Puzzle puzzle type within the current Puzzle file. Note that the Puzzle label box near the top of the screen now says "PUZZLE = 2 of 2".

Previous and Next Puzzle

You may now use the Prev Puzzle and Next Puzzle buttons to go back and forth between Puzzles within the file so that you may re-edit any of them. Once created, a Puzzle's puzzle type cannot be changed.

Theme

Notice that in the editing section, there is a "THEME" dialogue field in place of the "ANSWER" field of the Regular type Puzzles. Type in the Puzzle's Theme.

Tip: The Theme could be straightforward description, similar to or identical with the Puzzle's Category, or it might preferably be a sort of clever hint at what the Theme is. In that sense it is more similar to the Puzzle Clue of Regular Puzzle types.

Puzzle Word Clues

There is also now a corresponding list to the Puzzle Word List called Puzzle Word Clues. These function in an almost identical manner to crossword puzzle clues. Notice that the F1 key now tabs across between the two lists.

Master Auto

The button at the lower right (only visible when a puzzle is being edited) labeled "Master (---)" controls the updating of the Puzzle Master file. Since the build of this file can take a long time, it's default is to NOT Automatically update it after Saves and when going to Category editor (Manual mode). When already in Manual mode then pressing this button will generate the Puzzle Master file and go to Auto mode. When in Auto mode pressing the button switches to manual (with no build). The Puzzle Master file is very useful as a cross reference when looking for an overview of all puzzle files in it's directory or any particular detail (such as what puzzle file has the Bonus puzzle with the Theme 'U.S. Presidents"?)... Note that if an action takes a long time (such as saving a file or building the Puzzle Master file) then music is played while you wait.

You will be submitting your PZL files to Trilobyte Games.

Category Editing


Category Editor

You may now choose an existing Category although now we suggest you try creating a new one of your own. Click on Category field. In the Category Editor, select the Load button and load in Category.Suggestions.CAT. Select (highlight) a category or subcategory. Click in the dialogue box at the top of the Editor. It is now editable. Add a colon to the end of the tree string and type in the new Category. For example, expand "History" and select "World". In the editable box add a colon to the tree string and type in "Anchient". It should read "History : World : Anchient". Hit <Return>. You misspelled "Ancient". Select "Anchient" from the tree. Select it again and you may now type it correctly and hit <Return>. Or you may edit it in the editing box at the top of the window. Select the Save button to save the newly altered CAT file.

Test the new Bonus Puzzle. Use the "Clean" button to discard blank fields. Save your Puzzle file.

Tip: Since this is an early version of the Puzzle Editor, keep backup copies of your saved files.

Tip: Load one of the included PZL files to see examples of previously created puzzles.
